# 🌐 Simple 3-Page Bootstrap Website

This is a basic front-end web project built using **HTML, CSS, and Bootstrap**. The website consists of three main pages: **Home**, **Registration**, and **Login**. It is designed for beginners who want to understand how to structure a simple multi-page website.

---

## 📌 Features

* 🏠 **Home Page**

  * Introduction to the website
  * Navigation bar for easy access
  * Overview of services or content

* 📝 **Registration Page**

  * User-friendly form
  * Input fields for user details (e.g., name, email, password)
  * Basic validation using HTML

* 🔐 **Login Page**

  * Simple login form
  * Fields for username/email and password
  * Clean and responsive layout

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap (for responsive design and styling)
